# QuiltColourGenerator
For mum, a simple colour generator for her quilts.
Fully vibe coded with copilot. Seemed a good little project to give it a spin with.

## 🎨 About
This is a web-based tool that generates random color patterns for quilts. Simply choose your colors, set the grid size, and generate beautiful random patterns!

## 🚀 Live Demo
Visit the [Quilt Colour Generator](https://agilethief.github.io/QuiltColourGenerator/) to start creating patterns.

## ✨ Features
- **Custom Colors**: Add or remove colors from your palette using the color picker
- **Flexible Grid Size**: Choose any grid size from 1x1 to 50x50
- **Random Generation**: Each click generates a unique random pattern
- **Visual Preview**: See each color in your palette with its hex code
- **Responsive Design**: Works on desktop, tablet, and mobile devices
- **No Installation**: Runs entirely in your browser

## 🎯 How to Use
1. **Set Grid Size**: Enter the number of rows and columns you want (e.g., 10 x 12)
2. **Choose Colors**: 
   - Use the color picker to select a color
   - Click "Add Colour" to add it to your palette
   - Click the × button on any color to remove it
3. **Generate**: Click the "Generate Grid" button to create your random pattern
4. **Regenerate**: Click "Generate Grid" again to create a new random pattern with the same settings
